Kinematics Inside V-JEPA 2

Where does a frozen video encoder represent a moving disk's direction, speed and acceleration, how many dimensions does each take, and can it be steered? We reproduce the probing, nullspace and steering methods of Joseph et al. (arXiv 2602.07050) on the supplied synthetic clips. We ran each experiment twice, once with our own protocol and once with the paper's protocol as literally as its text allows.

Summary

  • A
    All three variables are linearly decodable from the first transformer block. Our ridge probe gets R² 0.86 for direction and 0.98 for speed and acceleration. The paper's own probe protocol gets 0.67, 0.87 and 0.82 at the same block. A randomly initialised V-JEPA scores 0.84–0.93, so on these clips one attention block over mean-pooled tokens already exposes the motion.
  • B
    Direction improves gradually with depth, with no sharp jump at the paper's layer 8. Error falls from 11° to 3.5° by our layer 12. The paper's own appendix (C.5, Fig. 18a) says mean-pooled direction also "improves more gradually" in their data; its sharp transition is in per-patch probes, which we have not run yet. Early-layer scores depend strongly on probe type and training-set size.
  • C
    Each variable spans tens of dimensions. Nullspace probing needs about 50–60 removed dimensions before R² drops below 0.3, the same order as the paper. Removing random directions does nothing. Removing the top 4–13 principal components wipes decoding out. Redundancy drops sharply between our layers 7 and 8.
  • D
    Paper-style steering reproduces at the layer where it is applied. Following the paper's C.12 procedure, the error to a 90° target falls from about 79° with 1 probe to 15° with 20 (7° with 224-px input). The paper reports 11.9°.
  • E
    The steering does not survive later layers. After the same edit is written into every token and the network runs on, direction error to target goes 4° → 25° → 45° → 73° within three blocks. The injected shift is actively cancelled: about half of it is gone after one block.
  • F
    "Acceleration" is mostly displacement. Applied to constant-velocity clips, where the true acceleration is 0, the acceleration probe predicts 6.8 m/s² on average and tracks how far the disk travelled with r = 0.993. The paper's datasets have the same confound.

FEATURES

Model and features

The encoder is facebook/vjepa2-vitl-fpc64-256, kept frozen. The predictor is never used. The checkpoint was trained on 64-frame clips; here it sees 16 frames.

Preprocessing
The HF processor's default resizes to 292 px and centre-crops to 256, which would cut about 7% off each border and could clip the disk. The clips are already 256², so we only rescale and normalise.
224-px variant
The paper's App. C.6 describes 224×224 input (1,568 tokens). We ran every paper-protocol experiment at both 256 px (native checkpoint) and 224 px (bicubic resize of the full frame).
Controls
A randomly initialised V-JEPA 2 with the same architecture; raw pixels (red channel, 32×32 per frame, linear); the disk's centroid trajectory with degree-2 polynomial features.

How clean is the paper's split?

Only partly. In layer-wise probing, the literal reading of App. B picks the best of 20 configurations on the same fold it reports. In practice the inflation is small here: the nested version is at most 0.025 lower. Nullspace probing has no separate test set. In steering, the steering subspace comes from train, but the evaluation probe is trained on the test clips it then reads.

Why does direction look earlier here than in the paper?

We changed two things at a time, probe type and data regime, on the direction set. "Paper-like" keeps only constant-velocity clips at the paper's 8 directions (0°, 45°, …, 315°), which is 96 clips. That is a quarter of the paper's 392, so it exaggerates the effect of little data. All four probe types use 5-fold CV with hyper-parameters chosen on an inner split.

Reading the paper directly

App. C.5, p. 26: "direction-related signals are already present in early layers, but remain tightly coupled to specific spatial locations … Mean-pooled probes can nevertheless achieve modest performance by linearly combining these fragmented signals … per-patch probe performance rises abruptly at the emergence zone, while mean-pooled performance improves more gradually." Our mean-pooled results agree with this. The sharp claim to test next is per-patch probing (their Fig. 18a, c).

EXPERIMENT 3

Multi-probe subspace steering

The first N nullspace probes span a subspace V. For a clip's pooled activation x, the coordinates inside V are replaced by the values that make every probe read the target, and everything outside V is kept (App. C.12, Eq. 8). We evaluate in two places: at the same layer, as the paper does, and after letting the remaining blocks run.

CONTROL

Displacement confound

The speed set has no acceleration and the acceleration set always starts from rest. Within each set, the distance travelled over 0.67 s determines the label, so a probe can succeed by reading where the disk ends up. To test this, we applied the layer-12 acceleration probe to the speed clips, whose true acceleration is 0.

Acceleration probe applied to constant-velocity clipsValue
Mean predicted acceleration (true value 0)6.76 m/s²

The probe reads distance travelled. The paper builds its datasets the same way, so its claims about acceleration face the same confound. The direction set mixes constant-velocity and accelerating clips over overlapping distances, which allows a direct test: can the representation tell "accelerating" from "constant velocity" when distance is matched?

NEXT

Limits and next steps

  • Per-patch probes. This is where the paper's sharp transition lives (Fig. 18a, c), and we have not run it yet.
  • Training-set size sweep. Probe R² by layer at 77, 150, 314 and 600 training clips would show directly how much early-layer decodability depends on data.
  • Acceleration test with distance matched. Use the mixed direction set to classify motion type when distance travelled is matched.
  • Stronger steering. Add Δ only to disk tokens, re-apply at every layer, or steer later in the network, to find an edit the model does not undo.
  • Differences from the paper that remain. Our stimulus is flat 2D (theirs is a shaded 3D sphere on a textured floor); we use 64 directions (theirs 8); some protocol details are unspecified (epochs, batch size, feature scaling, CV groups). Paper reference values were read off plots and are approximate.
